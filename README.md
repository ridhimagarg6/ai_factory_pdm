## 📌 Overview

Unplanned machine downtime costs Indian factories **₹7 million per hour**. Every existing predictive maintenance solution requires IoT sensors costing ₹5–50 lakh per factory — completely out of reach for India's 63 million SMEs.

This project builds a **zero-hardware, multi-label ML pipeline** using only historical operational data that:
- Predicts **5 failure types simultaneously** (TWF, HDF, PWF, OSF, RNF)
- **Detects data drift** per failure type using DDM and auto-retrains the model
- Applies **cost-sensitive learning** — prioritising expensive failures (HDF=₹85K) over cheap ones (RNF=₹5K)
- Simulates **Indian SME real-world noise** (power cuts, festival shutdowns, sensor drift, human errors, shift gaps)

---

## 🔧 Problem vs Solution

| Problem | This Project |
|---|---|
| Single failure prediction only | Multi-label: all 5 failures simultaneously |
| Static model — degrades silently | DDM per-failure drift detection + auto-retraining |
| All failures treated equally | Cost matrix: HDF=₹85K → RNF=₹5K |
| Requires ₹5–50L IoT hardware | Zero hardware — historical data only |
| Clean data assumptions | Indian SME noise simulation at 4 severity levels |

## 🔄 Pipeline — How to Run

Run each file in order:

### Step 1 — EDA & Analysis
```bash
python phase1.py
```
- Loads `ai4i2020.csv`
- Checks class imbalance, duplicates, sensor ranges
- Verifies physical failure conditions (TWF ≥ 200 min, HDF temp_delta < 8.6K, etc.)
- Generates 8 plots in `reports/phase1_plots/`

### Step 2 — Preprocessing & Feature Engineering
```bash
python phase2.py
```
- Engineers 3 new features: `temp_delta`, `power`, `wear_torque`
- Encodes product type: L=0, M=1, H=2
- Applies StandardScaler (fit on train only — no data leakage)
- Saves processed data to `data/processed/`

### Step 3 — Model Training & Evaluation
```bash
python new2.py
```
- Trains `MultiOutputClassifier` wrapping `XGBClassifier`
- Uses `RandomizedSearchCV` for hyperparameter tuning
- Applies hybrid rule + ML prediction for TWF (rare class)
- Prints per-failure F1 scores and classification reports
- Saves model to `data/processed/xgboost_model.pkl`

### Step 4 — Drift Detection & Auto-Retraining
```bash
python new7.py
```
- Monitors prediction errors per failure type using DDM
- Flags warning level and drift level thresholds
- Auto-retrains model using recent data when drift is detected
- Saves retrained model to `data/processed/xgboost_model_retrained.pkl`

### Step 5 — Final Demo (Machine Aging)
```bash
python fin.py
```
- Simulates gradual machine aging by incrementally increasing sensor values
- Demonstrates performance drop after drift
- Compares DDM retrain vs sliding window retrain
- Shows corrected samples after retraining

## 🗃️ Dataset

**AI4I 2020 Predictive Maintenance Dataset**
- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/601)
- 10,000 machine observations · 14 features · 5 failure type labels
- 3.4% failure rate — severe class imbalance
- License: CC BY 4.0

**Raw sensor features:**

| Feature | Description |
|---|---|
| Air temperature [K] | Ambient temperature around machine |
| Process temperature [K] | Internal machine operating temperature |
| Rotational speed [rpm] | Speed of machine shaft |
| Torque [Nm] | Load applied to machine |
| Tool wear [min] | Cumulative tool usage time |

**Engineered features (created in phase2.py):**

| Feature | Formula | Why |
|---|---|---|
| temp_delta | Process Temp − Air Temp | Detects HDF (threshold < 8.6 K) |
| power | Rotational Speed × Torque | Detects PWF (outside 3500–9000 W) |
| wear_torque | Tool Wear × Torque | Detects OSF (threshold > 11,000) |

**Target labels (multi-label):**

| Label | Full Name | Count | Cost if Missed |
|---|---|---|---|
| TWF | Tool Wear Failure | 46 | ₹25,000 |
| HDF | Heat Dissipation Failure | 115 | ₹85,000 |
| PWF | Power Failure | 95 | ₹45,000 |
| OSF | Overstrain Failure | 98 | ₹60,000 |
| RNF | Random Failure | 19 | ₹5,000 |

## ⚠️ Known Limitations

- **HDF and RNF F1 near zero** — caused by extreme class imbalance in test set (fewer than 20 test samples). This is a data constraint, not a modelling failure, and is explicitly documented.
- **DDM error-rate only** — does not detect feature-level drift. Future work: PSI, KS test, ADWIN.
- **Simulated dataset** — AI4I 2020 is synthetic. Real-world deployment requires validation on actual factory sensor data.
